# Cheers

Local, private dictation for macOS. Hold a key, talk, and the text lands in whatever field you're typing in. Speech recognition runs entirely on your Mac, on the Apple Neural Engine.

## Install

Download the latest `Cheers-x.y.z.dmg` from [Releases](https://github.com/backyardbit/cheers/releases), open it and drag Cheers into Applications. Requires an Apple Silicon Mac on macOS 26 or later.

## Shortcuts

| Action | Keys |
| --- | --- |
| Push to talk | Hold **fn**, release to transcribe |
| Hands-free | **Shift + fn** (or press shift while holding fn), then **fn** to finish |
| Cancel | **Esc** |

Set System Settings › Keyboard › "Press 🌐 key to" to **Do Nothing**, otherwise macOS opens the emoji picker on every press.

If a text field is focused, Cheers pastes into it (your clipboard is restored afterwards). If nothing editable is focused, the transcript goes on the clipboard so you can paste it wherever you want. The menu bar item also keeps the last transcript.

## How it works

- **Model:** [Parakeet Ultra 0.6B](https://github.com/FluidInference/FluidAudio/blob/main/Documentation/ASR/ParakeetUltra.md) through [FluidAudio](https://github.com/FluidInference/FluidAudio), compiled to Core ML with the encoder on the Neural Engine. It has the lowest English error rate in FluidAudio's lineup (2.13% / 3.81% WER on LibriSpeech clean/other) and transcribes a 7 second clip in about 100 ms on an M2 Pro.
- **Dictionary:** words you add are boosted acoustically by Parakeet's 110M CTC keyword spotter, then a deterministic pass fixes casing and rewrites anything listed under "sounds like". That also works for expansions such as `my email → jane@example.com`.
- **Cleanup:** filler words (um, uh) are removed, and NeMo inverse text normalization turns spoken numbers, dates and currency into written form.
- **Overlay:** a Liquid Glass pill with five translucent ribbons driven by live loudness and a five-band spectrum. It shows a lock and stop button in hands-free mode, and a moving comet while transcribing.

Models (~600 MB) download from Hugging Face on first launch and are cached in `~/Library/Application Support/FluidAudio`. Nothing else leaves your Mac.

## Building

Requires macOS 26+ and Xcode 26.

```sh
./scripts/build-app.sh            # builds build/Cheers.app
./scripts/build-app.sh --install  # also copies it to /Applications and launches it
swift test                        # unit tests for the hotkey state machine and post-processing
```

Grant **Microphone** and **Accessibility** access on first launch.

Ad-hoc signed builds lose the Accessibility grant on every rebuild. To keep it, create a stable local signing identity once; the build script picks it up automatically:

```sh
./scripts/create-signing-identity.sh
```

To check recognition without the UI:

```sh
.build/release/Cheers --transcribe path/to/audio.wav
```

## Releasing

```sh
./scripts/make-dmg.sh   # builds build/Cheers-<version>.dmg
```

With `CODESIGN_IDENTITY="Developer ID Application: …"` the app is signed with the hardened runtime, and with `NOTARY_PROFILE=<profile>` (created with `xcrun notarytool store-credentials`) the DMG is notarized and stapled so it opens without Gatekeeper warnings.

The app icon is generated by `swift scripts/make-icon.swift <dir>.iconset` followed by `iconutil -c icns`.
